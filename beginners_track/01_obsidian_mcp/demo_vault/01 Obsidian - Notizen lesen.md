# Obsidian: Notizen lesen

## Aufgabe

Verbinde Langflow direkt mit dem eingebauten MCP-Endpunkt des Plug-ins **Local REST API with MCP 5.1.0**. Gib nur Lese-Tools frei.

Frage anschließend:

> Fasse die Entwicklung von Honey for Heroes über alle Dateien in `MeetingNotes` zusammen. Nenne Zahlen mit Monat und Quelldatei.

Danach:

> Welche offenen Aufgaben betreffen Verteilung oder Nachhaltigkeit? Gruppiere sie nach Monat.

## Erwartetes Ergebnis

Der Agent findet June, July und August, liest die passenden Notizen und antwortet mit nachvollziehbaren Quellen. Keine Datei wird geschrieben, verschoben oder gelöscht.

## Beobachtungsfragen

- Brauchte der Agent erst eine Suche und danach einen Lesezugriff?
- Waren die Dateiinhalte bereits eine fertige Antwort?
- Welche deaktivierten Tools hätten den Vault verändern können?
